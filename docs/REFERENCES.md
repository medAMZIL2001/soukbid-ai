# Repository references

All seven repository landing pages were accessible in the GitHub review on 2026-11-25. The review used README files, repository trees and available source and dependency metadata. The projects were reviewed statically. No vendor calls, portal scrapers or upstream demos were run. Phase 0 uses original code.

## Source and dependency evidence

- **Tenders-Pilot** provides a CLI pipeline and a report script that builds summaries and sends email. The package manifest declares Playwright, Beautiful Soup, SQLAlchemy, FastAPI and pypdf. [Pipeline](https://github.com/AyoubBentahir/Tenders-Pilot/blob/main/main.py), [report script](https://github.com/AyoubBentahir/Tenders-Pilot/blob/main/generate_report.py), [manifest](https://github.com/AyoubBentahir/Tenders-Pilot/blob/main/pyproject.toml).
- **Multi-Agent Procurement RAG** defines graph nodes for comparison, risk, recommendation and reporting. Its ingestion module indexes policy documents independently. The backend manifest includes asyncpg and ReportLab alongside the API and document libraries. [Evaluation graph](https://github.com/jananichand/multi-agent-procurement-rag/blob/main/backend/app/graph/evaluation_workflow.py), [policy ingestion](https://github.com/jananichand/multi-agent-procurement-rag/blob/main/backend/app/services/rag/ingestion.py), [dependencies](https://github.com/jananichand/multi-agent-procurement-rag/blob/main/backend/requirements.txt).
- **TenderCortex** branches after retrieval, specialist routing and audit. The backend manifest includes LangChain's Groq and Hugging Face adapters, Qdrant, pypdf, pdfplumber and pytesseract. [Graph](https://github.com/GonzaloPontnau/TenderCortex/blob/master/backend/app/agents/rfp_graph.py), [dependencies](https://github.com/GonzaloPontnau/TenderCortex/blob/master/backend/requirements.txt).
- **Open Deep Research** defines a graph with clarification, research briefing, a supervisor, researcher tools, context compression and report generation. The manifest declares provider and search adapters as well as an MCP adapter. [Graph](https://github.com/langchain-ai/open_deep_research/blob/main/src/open_deep_research/deep_researcher.py), [manifest](https://github.com/langchain-ai/open_deep_research/blob/main/pyproject.toml).
- **GPT Researcher** exposes research, quick search, report writing and reference assembly. The runtime manifest includes LangChain, LangGraph, Ollama, LiteLLM and parser dependencies. [Agent](https://github.com/assafelovic/gpt-researcher/blob/main/gpt_researcher/agent.py), [dependencies](https://github.com/assafelovic/gpt-researcher/blob/main/requirements.txt).
- **Docling** maps source formats to configurable conversion pipelines. Its package delegates to `docling-slim[standard]` in the inspected manifest. [Converter](https://github.com/docling-project/docling/blob/main/docling/document_converter.py), [manifest](https://github.com/docling-project/docling/blob/main/packages/docling/pyproject.toml).
- **LLM Zoomcamp** includes examples for search and answer quality with helpers for retrieval, generation and usage. The evaluation module manifest includes Jupyter, minsearch, OpenAI and pandas. [Evaluation code](https://github.com/DataTalksClub/llm-zoomcamp/tree/main/04-evaluation/code), [module manifest](https://github.com/DataTalksClub/llm-zoomcamp/blob/main/04-evaluation/code/pyproject.toml).

## Design conclusions

- Keep collection provenance and corpus permissions independent of model choice.
- Start retrieval evaluation with a fixed corpus and baseline. Preserve the query and relevance labels for later comparisons.
- Keep mandatory-rule handling reproducible with explicit reasons. Use semantic retrieval to locate supporting evidence.
- Use versioned citations and bounded verification in the workflow. Inspect the original evidence when a citation is disputed.
- Before borrowing code, inspect the license at the exact source revision and keep required notices. Review data and model terms independently of source code terms. Reuse concepts through original implementation when a code license is unclear.
